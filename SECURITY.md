# Security policy

This project talks to power quality meters and handles their logins,
pre-shared keys and TLS. Please report security problems privately, not
in a public issue.

## Reporting

Use **Report a vulnerability** on the repository's
[Security tab](https://github.com/Project-Stateful-Zenith/zenith-kmb/security).
Include what is affected, how to reproduce it, and what an attacker could
do with it. You will get an answer within two weeks.

## Supported versions

Fixes go into the newest release. Older versions are not patched.
